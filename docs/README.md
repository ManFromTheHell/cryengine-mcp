## Engine notes

Written from work on one game project; the engine facts were measured on CRYENGINE 5.7.1, but some file names, level names and paths in the examples belong to that project. Read them as field notes.

| Document | What it covers |
|---|---|
| [CRYENGINE_BRIDGE.md](CRYENGINE_BRIDGE.md) | The editor's three command registries (console, editor commands, Python), their pitfalls, and a generated listing of the editor's Python API. |
| [CLAUDE_BRIDGE_OPS.md](CLAUDE_BRIDGE_OPS.md) | Operating the plugin and editor unattended (maintainer notes): deploy loop, self-test, watchdog, failure modes. |
| [engine-lifetimes.md](engine-lifetimes.md) | The four nested lifetimes of a CRYENGINE session (engine, editor, game, packaged build) and the bugs that come from holding a pointer across them. |
| [animation-pipeline.md](animation-pipeline.md) | Making animation clips with NVIDIA MotionBricks and Kimodo (optional; see [NOTICE.md](../NOTICE.md)). |

Some of the engine notes still mention the original game project. Where a statement and a tool's measured output disagree, trust the measurement.
