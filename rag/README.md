# Knowledge base (RAG corpus)

This file is generated by `python rag/build_corpus.py --readme`. To change its wording edit `do_readme()` in `rag/build_corpus.py` and regenerate; an edit made here is lost on the next run.

A searchable record of what was measured, broken and fixed while building this server and the Ashvale example (traps, silent engine failures, playbooks, tool descriptions). Many chunks are field notes: they name the example's levels and assets, may contain Windows paths from the author's machine and are partly written in the first person. Some chunks paraphrase or quote Crytek documentation or engine source; the licence of those sources was not checked. `query_knowledge("<question>")` (MCP) or `python rag/rag_query.py "<question>"` search it: BM25 over the title (x4), tags (x3) and body, filler words dropped, synonyms (x0.6) widening the query. The CRYENGINE manual is a separate index (`catalogs/docs_search.py`); where the two disagree, a measurement wins over the manual.

**538 chunks** (527 live, 11 superseded, 60 of them split children).

The filter understands case, plurals and the old category names (`traps`, `how-to`, `gamesdk-ai`, `open-problem` ...); the old name is kept on each chunk as the tag `cat:<old>`.

## Fields of a chunk

`id` (lowercase, hyphens), `title` (<= 140 chars), `category`, `tags` (the words a newcomer types), `source`, `content`, and
- `status`: `measured` / `read-from-source` / `hypothesis` / `superseded` / `unclassified` (nobody recorded the evidence; NOT 'wrong'). Now: measured 214, read-from-source 117, superseded 11, unclassified 196.
- `verified_in`: `none` (never run or seen), `editor`, `packaged`, `partial` (see `verified_note`), `unclassified`. Now: editor 42, none 75, packaged 38, partial 28, unclassified 355.
- `date` (YYYY-MM-DD it was written, empty when unknown), `superseded_by` (required when superseded), optional `history` (old text kept for the record), `parent` (the chunk it was split from), `verified_note`.

A chunk with `status: superseded` is NOT returned unless `include_superseded=True` / `--include-superseded`.

## Use

Run from the repository root:

```
python rag/rag_query.py "material renders black" --top 3
python rag/rag_query.py --cat trap --list
python rag/rag_query.py --verified-in none --list   # claims never seen working
python rag/rag_query.py --id npc-open-problem        # a replaced chunk, with its history
```

## Change it

```python
import sys; sys.path.insert(0, "rag")
import corpus_lib as L
L.upsert(dict(id="trap-x", title="Symptom as the title", category="trap", tags=["words", "a newcomer", "types"],
              source="where it was seen", content="...", status="measured", verified_in="editor", date="2026-01-31"))
```
`upsert` validates (required fields, tag types, title length, category list, duplicate ids and titles, dangling `superseded_by` / `parent`) and writes the corpus atomically (and the mirror copy, if `CRYENGINE_CORPUS_MIRROR` names one; that file must already exist). Nothing is written when the result has an error. Then `python rag/build_corpus.py --all`. Lint warnings: an open problem or hypothesis older than 14 days or undated, text naming a chunk id that does not exist, a chunk over 3000 characters (split it into one-symptom chunks).
